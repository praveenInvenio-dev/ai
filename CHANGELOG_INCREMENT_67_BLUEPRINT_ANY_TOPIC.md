# Increment 67 — Blueprint explainer for ANY topic (physics, chemistry, biology, maths, tech)

Includes Increments 55-66.

The blueprint format is no longer system-design shaped. The writer anchors every topic in one real situation
("a 400-tonne A380 taking off", "you braking in an auto", "a matchstick catching fire", "the sip of chai you drank") and
explains the actual mechanism the way a teacher draws it on the board.

## 9 new board-diagram beats (19 in total)
| Beat | What it draws | e.g. |
|---|---|---|
| `forces` | free-body diagram: object + labelled force arrows (direction, size, colour) | lift/weight/thrust/drag on a plane, friction, normal force |
| `motion` | the object actually moving with velocity arrow + trail: uniform, accelerate, decelerate, fall, projectile, circular | Newton's 2nd law, free fall, orbits |
| `graph` | axes + curve drawn live (linear, quadratic, inverse, exp, decay, sine, log, constant) + marked point | v-t graph, Boyle's law, decay |
| `equation` | formula built token by token, key symbol highlighted, every symbol explained | F = m × a, L = ½ ρ v² S C |
| `flow` | streamlines with moving particles around an airfoil / ball / through a narrowing pipe, LIFT arrow | Bernoulli, wing lift, blood flow |
| `parts` | labelled diagram with callouts (cell, atom, leaf, heart, eye, Earth layers, neuron), focus part glows | organelles, atom structure |
| `cycle` | stages around a loop with a travelling dot | water cycle, Krebs, heartbeat |
| `reaction` | reactants → products with the condition over the arrow | 2H₂ + O₂ → 2H₂O |
| `wave` | travelling wave with λ and A marked | sound, light, SHM |
Objects for forces/motion: box, ball, car, plane, rocket, person, apple, satellite, block, bird.

## Subject-aware writing (uses the Subject picker)
- Physics (JEE): free-body diagrams, motion, graph, formula with symbols, ONE numeric example, the classic mistake.
- Maths (JEE): picture/graph first, formula, worked example, common trap.
- Chemistry (NEET): what particles/electrons do, balanced reaction + condition, one number, common mistake.
- Biology (NEET): labelled structure, process step by step (pipeline/cycle), the fact NEET asks, the common confusion.
- CS/system design: devices, pipeline, fanout, buffers, charts. General: whatever a teacher would draw.
- Asker / series label follow the subject (YOUR FRIEND / JEE / NEET / INTERVIEWER; PHYSICS · 007 ...).
