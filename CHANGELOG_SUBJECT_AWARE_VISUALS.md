# Subject-aware visuals (health / biology / everyday topics)

Video (51) "why ears pop on a plane" was drawn with tech parts (app tiles with globe icons, a "container" as the
eardrum) because the icon set and the look were tech-only.

- 36 new icons: ear, eye, heart, lungs, tooth, bone, pill, syringe, stethoscope, virus, bacteria, cell, dna, drop,
  water, thermometer, hospital, plus, stomach, kidney, muscle, apple/food, leaf, sun, moon, wind, gauge, person,
  baby, family, home, car, bed, mask, microscope.
- The planner reports the subject ("domain"); a keyword check backs it up. Prompt rule: match the subject -
  health topics use anatomy icons and a person-centred running example, never servers/code/terminals.
- New "clinical" look (white-mint, teal structure, coral for warnings) picked automatically for health/biology
  lessons when the default tech style is selected (a note on the lesson says so; any other style is respected).
- Lessons can now include up to 3 generated framed illustrations (e.g. an ear cross-section) next to the diagram,
  drawn in a clean educational-medical style with no text in the image.
- Long tile names wrap to two lines instead of "Eustachi...".
