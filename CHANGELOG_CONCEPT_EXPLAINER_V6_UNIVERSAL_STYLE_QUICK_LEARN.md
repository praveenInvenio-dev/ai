# Concept Explainer V6 — Universal Reference Style + 60-second Quick Learn

- Enforced the technical tutorial reference palette for every Concept Explainer lesson, including jobs created from older clients or saved settings.
- Removed the visual-style selector from the Concept Explainer form; one consistent visual language is applied to every lesson.
- Tightened Quick Learn planning to 5–7 purposeful scenes and 115–135 spoken words, with a hook, one core idea, one visual example and a memorable takeaway.
- Added explicit short-form writing guidance: no filler, long introductions, forced quizzes, unnecessary lists or rushed coverage of broad topics.
- Three-minute lessons retain their longer scene and word targets.
- Runtime must still be tested in the user's Docker environment. Actual duration varies by language, speaking rate and pauses; the word target aims at 60 seconds, not a hard guarantee.
