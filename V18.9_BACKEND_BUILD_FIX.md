# v18.9 Backend Build Fix

## Fixes
- Removed the duplicate 6-argument `ProviderGateway.synthesizeWithVoice(...)` declaration that caused a Java compilation error.
- Made Lombok 1.18.34 an explicit provided dependency.
- Configured Maven Compiler Plugin 3.13.0 with an explicit Lombok annotation processor for Java 21 so entity getters/setters are generated reliably during Docker builds.
- Preserved the existing strict saved-voice preview/narration path; provider failures are not silently replaced by the mock voice.

## Verification target
Run:

```bash
docker compose -f docker-compose.yml -f docker-compose.gpu.yml up -d --build
```

The expected first gate is a successful backend `mvn -B clean package -DskipTests` followed by the normal Compose startup.
