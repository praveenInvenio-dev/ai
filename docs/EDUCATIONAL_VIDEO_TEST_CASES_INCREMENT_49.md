# Educational video prompt QA cases — Increment 49

Use these as manual generation checks after deploying the prompt changes. Expected output remains in the existing JSON schemas.

## 1. JEE Physics Short
- Topic: Projectile motion — why horizontal velocity stays constant (JEE Main 2027 syllabus-style practice)
- Audience/level: JEE Main aspirant, Class 11
- Format: 60-second vertical Short, English or Hindi
- Must demonstrate: launch vector, horizontal/vertical components, a correctly drawn trajectory, gravity acting downward, one worked numerical example with units, one misconception check.
- Must not: claim the question is a PYQ, invent exam weightage, draw inaccurate graph axes, or imply gravity changes horizontal velocity in ideal projectile motion without air resistance.

## 2. NEET Biology Long Lesson
- Topic: Nephron filtration and urine formation
- Audience/level: NEET UG aspirant
- Format: 8-10 minute YouTube lesson
- Must demonstrate: correctly ordered nephron structures and process flow, filtration/reabsorption/secretion distinctions, a labelled diagram, one retrieval question and answer, and a concise misconception correction.
- Must not: turn the lesson into personal diagnosis/treatment advice or invent syllabus/PYQ claims.

## 3. Younger learner mathematics
- Topic: Equivalent fractions using pizza slices
- Audience/level: age 8-10
- Format: 2-minute tutorial
- Must demonstrate: one objective, a visual comparison of equal quantities with different partitions, one prediction question, answer reveal and a practice question.
- Must not: use manipulative engagement pressure, ask for personal information, or assume the publishing platform's Made for Kids designation automatically.

## 4. School science experiment
- Topic: Why does a shadow change length during the day?
- Audience/level: middle school
- Format: 60-second Short plus a longer lesson outline
- Must demonstrate: safe simple model using a lamp and object, changing angle/position, clear cause-and-effect and one caveat about the model versus the Sun/Earth system.
- Must not: state that the Sun literally moves around Earth.

## 5. Long-form technical tutor
- Topic: How a database index speeds up a query
- Audience/level: beginner developer
- Format: 10-minute YouTube lesson
- Must demonstrate: same sample dataset, table scan versus index lookup, accurate simplified visualization, small SQL example, trade-off for writes/storage, recap and next-topic suggestion.
- Must not: imply every index always makes every query faster.

## Review checklist
- [ ] Hook is specific and honestly resolved.
- [ ] Learning objective is clear and suited to the audience/age/level.
- [ ] Worked example has correct arithmetic, units and assumptions.
- [ ] PYQ and syllabus claims have verified source/year metadata or are clearly labelled original practice.
- [ ] Visuals explain state changes and match the spoken narration.
- [ ] Generated images are not used as the authority for equation text, graph scale or scientific labels.
- [ ] Captions, narration language and technical vocabulary are consistent.
- [ ] No filler intro, artificial suspense, copied creator content or coercive child-directed CTA.
- [ ] For time-sensitive trend claims, a current source and date are available.
