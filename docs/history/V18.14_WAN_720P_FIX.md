# v18.14 Wan 2.2 TI2V-5B quality fix

Clip inspected: 480x832, 16 fps, 81 frames, ~0.8 Mbps.
Wan2.2 TI2V-5B is trained for 720p@24fps (1280x704 / 704x1280); 480p is not a supported size.

Changes (Wan only, H3 untouched):
- Default size 704x1280 (vertical) at 24 fps; 1280x704 recommended for wide shots.
- Steps 16 -> 30, cfg 5, max clip 5 s (121 frames).
- VAEDecode -> VAEDecodeTiled in both TI2V-5B graphs so 720p x 121 frames decodes on 16 GB.
- Empty negative prompt now falls back to Wan 2.2's official default negative prompt.

Expect roughly 2-3x longer generation per clip than the 480p/16-step setting.
