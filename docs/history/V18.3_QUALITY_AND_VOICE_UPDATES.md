# v18.3 quality and voice update

This update is additive and keeps the existing image/video/TTS providers intact.

## Added
- Rich provider-neutral TTS direction: emotion intensity, delivery, emphasis,
  breath, paralinguistic event, acting direction and CosyVoice reference transcript.
- CosyVoice 3 provider adapter and optional Docker sidecar/profile.
- Reusable voice library support for ChatterBox and CosyVoice recordings.
- Optional CosyVoice reference transcript in the Record Voice UI.
- First-class episode narrator VoiceProfile endpoint and persistence.
- Scene AudioSpec persistence for ambience/music/SFX/dialogue priority.
- Expanded cinematic SceneVisualSpec motion/effects fields.
- Quality-profile hook for an optional newer/high-quality ComfyUI image workflow.
- GPU build override for ChatterBox/CosyVoice.

## Fixed/improved
- VoiceSegment rich fields now survive JSON parsing and reach TTS providers.
- ChatterBox paralinguistic events are converted to native tags inside the
  ChatterBox provider only; Piper/Sarvam never speak the tags aloud.
- Removed random per-line TTS speed jitter; Voice Director metadata now controls
  intentional variation, preserving character voice consistency.
- Wan/image workflow selection remains provider/workflow-aware and existing
  workflows are preserved as fallback.

## Compatibility
- Existing Piper, IndicF5, Sarvam, DreamShaper/SDXL and Wan workflows remain.
- CosyVoice is optional and is not started by the default compose profile.
- The newer image model hook is opt-in; leaving its two environment variables
  blank produces the same existing image workflow behaviour.
