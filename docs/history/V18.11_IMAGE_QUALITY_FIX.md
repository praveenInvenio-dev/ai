# v18.11 Image Quality + Consistency Fix

## Problem
QUALITY episodes rendered with TWO models:
- scenes with a locked character -> SDXL DreamShaperXL-Lightning + IPAdapter
- scenes without a character      -> Qwen Image 2.1
Result: mixed styles, weak identity, empty backgrounds. Specific causes:
1. Lightning (a 4-6 step model) ran with Qwen-tier settings: 20 steps, cfg 1.0, 576x1024
   (about half of SDXL native resolution). Over-smoothed, soft, negative prompt ignored.
2. IPAdapter weight_type "style transfer" carries style, not face/identity.
3. Prompt budget picked Qwen size (380 tokens) for the SDXL scenes; CLIP fades everything
   past ~150 tokens, so the background/environment part of the prompt was effectively lost.
4. Previous scene's generated image was reused as the next scene's reference -> drift compounds.
5. Character reference sheets were drawn by Lightning at 4 steps as a multi-view collage.
6. Qwen ran at 576x1024 (0.59 MP), well below its 1024x1024-class native budget.

## Fix
- One model for every scene: Qwen Image 2.1 with locked character references passed natively
  into TextEncodeQwenImage21 (images.image_1 / image_2 + VAE).
  New workflows: qwen-image-2-1-16gb-ref.json, qwen-image-2-1-16gb-ref-dual.json.
- Prompt maps <image1>/<image2> to the first/second character and tells the model to keep the
  character on-model but draw a new pose and a fully detailed background.
- Characters with references are ordered first so the mapping is correct; up to 2 references
  per scene (no more "exactly 2 characters, both with refs" rule).
- No previous-scene image fed back as a reference in Qwen mode.
- Character master references drawn by Qwen too (single clean full-body figure, 1024x1024).
- Qwen size: 768x1344 base (~1 MP), 30 steps, RealESRGAN x2, final 1080x1920.
- If ComfyUI lacks Qwen 2.1 nodes -> automatic SDXL fallback with proper SDXL defaults
  (no more 400 failed scene).
- docker-compose now passes COMFYUI_QWEN_*, LOCAL_AI_ANIMATION_ENABLED_IN_STORY_PIPELINE
  and all MiniMax H3 vars to the backend (H3 video VAE default -> fp16).

## Toggle
COMFYUI_QWEN_USE_REFERENCES=false restores the old SDXL+IPAdapter path for reference scenes.

## After upgrading
1. Update ComfyUI (Qwen 2.1 nodes) and download Qwen models.
2. Episode quality profile must be QUALITY.
3. Character Studio: regenerate each character's reference with Qwen and LOCK it.
4. Regenerate scene images.
