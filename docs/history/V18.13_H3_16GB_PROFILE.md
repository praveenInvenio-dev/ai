# v18.13 MiniMax H3 16 GB profile

Replaces the hard 24 GB H3 guard with a profile. Wan 2.2 code paths unchanged.

## Profile 16gb (default)
- DiT: minimax_h3_fl2va_pruned_w6a8.safetensors (16 GB file, Comfy-Org/MiniMax-H3)
  Ref2VA: minimax_h3_ref2va_pruned_w6a8.safetensors (only for voice-reference mode)
- TE: qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors, video VAE fp16, audio VAE fp32
- 480x832, max 5 s, 20 steps (base model; 8 was a Turbo-only setting)
- Gate: VRAM >= 15000 MB (nvidia-smi), host RAM >= 48000 MB (/proc/meminfo)
- Before each H3 job: POST /free to ComfyUI (unload Qwen/Wan weights)

## Profile 24gb
LOCAL_AI_ANIMATION_MINIMAX_H3_PROFILE=24gb -> pruned INT8 DiT, 24000 MB floor (old behaviour).

## Overrides (.env)
LOCAL_AI_ANIMATION_MINIMAX_H3_MODEL / _REF2VA_MODEL / _STEPS / _MIN_VRAM_MB / _MIN_RAM_MB /
_WIDTH / _HEIGHT / _MAX_DURATION_SECONDS / _FREE_VRAM. Blank/0 = profile default.
_MIN_RAM_MB=0 skips the RAM check.

## Only if VAE decode crashes ComfyUI (reported on some NVIDIA setups)
COMFYUI_EXTRA_CLI_ARGS=--disable-async-offload --disable-pinned-memory
Note: ComfyUI-wide flag, also affects Wan/Qwen speed. Leave unset unless needed.
