# v18.12 Backend Build Fix

## Fix included

The Docker Maven build reached Java compilation successfully but failed at `ProductionPipelineService.java:909` because `VideoGenerationRequest` is a 10-field record while that call supplied only 9 arguments.

The request record fields are:

1. startingImagePath
2. prompt
3. negativePrompt
4. durationSeconds
5. width
6. height
7. workflow
8. voiceReferenceAudioPath
9. seed
10. steps

The production pipeline call was missing the `seed` argument. It now passes `null` for the seed and retains `qualityVideoSteps(episode)` as the final steps argument.

No other workflow behavior was changed.
