# AI Story Studio v18.2 — Production Reliability & Consistency Update

## What changed

### Final video assembly
- Scene clips are rendered and validated individually before assembly.
- The normal assembly path concatenates complete scene clips first and mixes BGM in a separate pass.
- The final MP4 is duration-checked against the complete scene timeline.
- A partial/truncated final video is now treated as a failed render instead of a successful output.
- Optional xfade/acrossfade transitions are disabled by default on constrained hardware and have an automatic full-length concat fallback.
- Shorts use an explicit duration window and validate the resulting file.

### Character consistency
- Stable scene seeds are derived from episode/style/character identity.
- An approved Character Reference is preferred.
- If no reference exists, scenes containing the same character can carry the previous generated scene forward as a reference for IPAdapter conditioning.
- SD1.5 and SDXL IPAdapter workflows are separated automatically.
- Reference conditioning is moderate so the scene prompt remains responsible for action/composition.
- A missing IPAdapter workflow does not intentionally ship a placeholder; the pipeline can retry the same deterministic scene without reference conditioning.

### Image generation
- SDXL-Lightning automatically switches from `dpmpp_2m/karras` to `euler/sgm_uniform`.
- Resolution remains controlled by `.env`; no hardcoded latent dimensions were added.
- Placeholder-image fallback defaults to disabled so generation failures are visible rather than silently becoming bad frames.
- GPU Docker no longer exports an empty `OMP_NUM_THREADS`, fixing the `libgomp: Invalid value for environment variable OMP_NUM_THREADS` warning.

### Voice
- Default example voice is now Microsoft Edge's `en-IN-NeerjaNeural` through the existing local TTS sidecar.
- Edge TTS failure falls back to local Piper instead of producing silence.
- The existing scene-level synthesis, pauses, emotion pacing and conservative FFmpeg voice mastering are retained.

### Background music
- If the user uploads music, it remains highest priority.
- If no preset is selected, a mood-based bundled music preset is selected automatically.
- The exact BGM track used is copied into the episode's asset directory and therefore appears in the Complete Package ZIP.
- BGM is looped, mixed below narration and dynamically ducked while narration is speaking.
- The music bed cannot shorten the final video.

## Recommended MX450 profile

For a 2 GB MX450:

```env
COMFYUI_MODEL=DreamShaper8_LCM.safetensors
COMFYUI_WORKFLOW=character-consistent-story
COMFYUI_WIDTH=512
COMFYUI_HEIGHT=512
COMFYUI_STEPS=4
COMFYUI_CFG=1.0
COMFYUI_SAMPLER=lcm
COMFYUI_SCHEDULER=sgm_uniform
COMFYUI_EXTRA_CLI_ARGS=--lowvram
COMFYUI_FALLBACK_PLACEHOLDER=false
OMP_NUM_THREADS=4
VIDEO_TRANSITIONS_ENABLED=false
AUTO_MUSIC_ENABLED=true
TTS_VOICE=edge:en-IN-NeerjaNeural
```

For DreamShaperXL-Lightning, use a GPU-appropriate resolution such as 768x768. The provider automatically corrects a legacy dpmpp/karras sampler/scheduler combination to Euler/SGM-Uniform when the checkpoint name contains `Lightning`.

## Verification

Python services and all workflow JSON files were syntax-checked during packaging.

A full Maven build could not be executed in the packaging environment because Maven is not installed there. The project should therefore be rebuilt with:

```bash
docker compose -f docker-compose.yml -f docker-compose.gpu.yml up -d --build
```

before deployment.
