# v18.9 — H3 Storyboard Native Audio

## What changed

- Storyboard scenes now expose a dedicated **Video direction** field alongside narration.
- The selected storyboard image is used as the exact H3 I2V visual anchor.
- Scene narration and character dialogue are converted into MiniMax H3 audiovisual prompts using stable speaker IDs and `<d>[Language] ...</d>` dialogue tags.
- Narration is generated by H3 in the same video generation pass as video, ambience, SFX and music. A second TTS track is not muxed over successful H3 scenes.
- Scene duration is automatically estimated from narration length and explicit voice pauses, then clamped to 3–10 seconds for the 16GB H3 profile.
- Storyboard generation uses 10 H3 steps by default (`QUALITY` keeps 20 steps). This is a faster mode using the existing W6A8 graph and does not require a new Turbo LoRA.
- The final FFmpeg AI-video renderer now preserves native audio from an AI video when no external audio track is supplied.
- H3 failures remain isolated per scene; the existing TTS + 2.5D path is used for failed scenes.
- Story-pipeline H3-all-scenes mode is configurable through `LOCAL_AI_ANIMATION_H3_FOR_ALL_SCENES` and enabled in the packaged `.env`.
- The packaged story-pipeline workflow is set to `minimax-h3-image-to-video`.

## H3 prompt structure

Each scene is sent as:

1. Image alignment instruction
2. Timed shot / motion description
3. Stable speaker IDs
4. Native narration/dialogue using `<d>` tags
5. Explicit soundscape
6. Explicit non-diegetic music

The image remains the visual source of truth so character identity and the selected storyboard composition are not regenerated from scratch.
