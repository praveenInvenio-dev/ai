# Visual variety - lessons no longer all look the same

## 13 new teaching devices (every format, every look)
timeline, steps (horizontal / vertical), compare (A vs B with ✓/✗), cycle, layers / pyramid, venn (2-3 sets),
meter (dial), checklist (do / don't), analogy (idea ≈ everyday thing), matrix (2x2 with axes), formula (with legend),
pie (donut + legend), tree (2-level hierarchy). Drawn from the theme colours, so they fit tech, clinical, reel and
3D-blueprint looks. Model synonyms map onto them (vs, flow, hierarchy, quadrant, equation, donut ...).

## The planners must use them - and vary
- Every outline scene names its main visual "device"; the writer builds the scene around it.
- Rules: no two consecutive scenes with the same main device; minimum distinct devices per lesson
  (1-min / 60-s short: 4, 3-min / breakdown: 6, 10-min: 9); vary composition (centred, split, flow, grid).
- A different TEACHING APPROACH per lesson (story-first, myth-buster, build-it-from-scratch, question ladder,
  compare-and-contrast, how-we-got-here, analogy-first, mistake-driven, numbers-first), so the arc changes too.
- Each lesson's notes show its approach and the kinds of visuals used, plus a note if variety came out low.
